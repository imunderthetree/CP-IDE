# CP-IDE v1.0.1

CP-IDE v1.0.1 is a small maintenance release focused on packaging and release reliability.

## Highlights

- Fixed the lint dependency mismatch so fresh `npm ci` installs work again on the release branch.
- Refreshed Rust dependencies used in the desktop app, including `reqwest` and `rusqlite`.
- Updated frontend build tooling and kept the lint stack on compatible versions.
- Updated GitHub Actions workflow dependencies used for CI and publishing.
- Clarified the local Windows release flow so the MSI installer can be built and uploaded manually with matching metadata.

## Install Notes

- Windows 10/11 is the supported platform for this release.
- If you want portable compilers bundled into the installer, place them under `src-tauri/compilers/` before building.

## Assets

- Windows executable: `src-tauri/target/release/cp-ide.exe`
- Windows installer: `src-tauri/target/release/bundle/msi/`
