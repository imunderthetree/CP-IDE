# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a Vulnerability

Please do not report security issues in public GitHub issues.

If the repository has GitHub Security Advisories enabled, use that private reporting flow. Otherwise, contact the maintainers privately through the contact details published on the repository profile before sharing any exploit details.

Include the following when possible:

- A clear description of the issue and the impact.
- Steps to reproduce the problem.
- Any proof-of-concept code, logs, or screenshots that help confirm the report.
- Your preferred contact method for follow-up questions.

We will acknowledge good-faith reports as quickly as possible, work on a fix, and disclose the issue publicly only after a patch or mitigation is available.
